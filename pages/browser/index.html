Browser workbench — spec gap reproduction

Compiler Explorer for USD spec gaps. Each row links to a per-case runner (app.html?case=LEAN-111) that executes the same ops list against the spec/Lean model column, the LightUSD WASM backend, and the OpenUSD oracle backend, and diffs the results per op.

FindingTitleLean→specLightUSD wasmOpenUSD oracleOpen

How to read
  • Lean column — expected results from the formalization (generated vectors + registry row).
  • Backend columns — live WASM runs when `wasm/manifest.json` pins a valid artifact; otherwise the last recorded native run.
  • Open the case page to edit layer text / ops and see per-op diffs.
